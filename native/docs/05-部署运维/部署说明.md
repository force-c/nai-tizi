# 部署说明

## 配置

应用使用 `QUICK_ADMIN_APP_ENV` 选择配置文件：

- `dev`（默认）：`conf.dev.yaml`
- `prod`：`conf.prod.yaml`

该变量只是配置文件选择器，不属于 `Config` 结构。其他配置使用同名 `QUICK_ADMIN_*` 环境变量覆盖 YAML，例如：

```bash
export QUICK_ADMIN_APP_ENV=prod
export QUICK_ADMIN_DATABASE_DSN='host=db user=quick_admin password=... dbname=quick_admin sslmode=require'
export QUICK_ADMIN_REDIS_ADDR='redis:6379'
export QUICK_ADMIN_JWT_SECRET='至少 32 字符的随机密钥'
./quick-admin
```

优先级：代码默认值 < YAML < 环境变量。生产配置若启用 CORS，应用会拒绝启动。

## 构建

```bash
go build -trimpath -o bin/quick-admin ./cmd/api
```

Docker 构建上下文必须是 `native`：

```bash
docker build -f dockerfile/Dockerfile -t quick-admin-native .
```

## 数据库

服务连接 PostgreSQL 后自动执行 Goose migration：

- 迁移目录：`internal/database/migrations/sql/`
- 版本表：`goose_db_version`
- 迁移 SQL 通过 Go embed 打入二进制
- 迁移失败时服务立即退出

项目不使用 GORM AutoMigrate，也不从 `deploy/sql` 初始化数据库。任何表、索引、约束或系统参考数据变更都必须新增迁移版本。

## 探针

```bash
curl http://127.0.0.1:9009/health/startup
curl http://127.0.0.1:9009/health/live
curl http://127.0.0.1:9009/health/ready
```

生产部署通过 Nginx 同源代理前端与 API，应用层 CORS 保持关闭。
