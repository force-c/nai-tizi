# 认证系统使用指南

## 客户端

系统迁移创建逻辑客户端 `web-admin`。客户端 ID 用于选择授权方式与 Token 时长，不是客户端密钥；浏览器端无法安全保存共享密钥，因此模型中没有 `clientKey` 或 `clientSecret`。

`web-admin` 默认支持：`password,email,sms,wechat`。

## 登录

统一入口：`POST /login`。

密码登录：

```json
{
  "clientId": "web-admin",
  "grantType": "password",
  "username": "admin",
  "password": "your-password",
  "uuid": "captcha-id",
  "code": "captcha-answer"
}
```

微信登录：

```json
{
  "clientId": "web-admin",
  "grantType": "wechat",
  "wxCode": "code-returned-by-wx.login"
}
```

微信方案是纯服务端换码：后端使用 `wxCode` 调用微信 `jscode2session`，按 OpenID 查询或创建用户。接口不接受客户端提交的 OpenID，也不把短信验证码作为微信登录的必需步骤。

## Token

登录返回 Access Token、Refresh Token 和各自有效期。Access Token 放在请求头：

```text
Authorization: Bearer <access-token>
```

刷新：

```http
POST /auth/refresh
Content-Type: application/json

{"clientId":"web-admin","refreshToken":"..."}
```

Refresh Token 单次使用。刷新成功后旧 Access Token 和旧 Refresh Token 都立即失效，并返回一组新 Token。

登出：`POST /logout`。服务端会撤销当前 Redis 会话，而不是只依赖 JWT 自然过期。

`auth.allowConcurrent=false` 时，新登录会撤销同一用户、同一客户端的其他会话；为 `true` 时每次登录仍创建独立会话，不共享 Token。

## 初始管理员

数据库迁移不会写入默认密码。使用 `cmd/usermgr` 创建或重置管理员，密码只能来自 `QUICK_ADMIN_USERMGR_PASSWORD`，详情见 `native/README.md`。
