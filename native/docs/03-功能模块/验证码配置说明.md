# 验证码配置说明

验证码是可插拔的登录校验能力，不是所有登录方式的固定步骤。

## 类型

- `image`：密码登录的人机校验；启用后 `password` 登录需要 `uuid + code`。
- `sms`：短信登录；`sms` 登录需要 `phonenumber + code`。
- `email`：邮箱登录；`email` 登录需要 `email + code`。

微信登录不使用上述验证码。客户端提交 `wxCode`，服务端直接与微信交换 OpenID/UnionID。

## 配置

```yaml
captcha:
  image:
    enabled: true
    length: 4
    width: 120
    height: 40
    expire: 300
  sms:
    enabled: false
    length: 6
    expire: 300
  email:
    enabled: false
    length: 6
    expire: 300
```

短信、邮件提供商启用后，其密钥必须通过对应 `QUICK_ADMIN_*` 环境变量注入。验证码只保存于 Redis，验证成功后立即消费，避免重放。

公开接口：

- `GET /captcha/enabled-types`
- `GET /captcha/image`
- `POST /captcha/sms/send`
- `POST /captcha/email/send`
